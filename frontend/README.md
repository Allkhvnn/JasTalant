# JasTalant Frontend

Frontend CRM на React, TypeScript и Vite.

## Команды

```powershell
npm.cmd install
npm.cmd run dev
npm.cmd run lint
npm.cmd run build
```

Dev-сервер работает на `http://localhost:5173`. Запросы с путём `/api` проксируются на `http://localhost:8080`, поэтому отдельная CORS-конфигурация для локальной разработки не требуется.

Чтобы изменить адрес backend, скопируйте `.env.example` в `.env` и задайте `VITE_API_PROXY_TARGET`. Файл `.env` не попадает в Git.

## Структура `src`

- `app` — инициализация приложения и глобальные стили;
- `pages` — страницы, добавляются вместе с маршрутизацией;
- `widgets` — крупные блоки страниц;
- `features` — пользовательские сценарии: вход, регистрация, посещаемость;
- `entities` — модели академии, группы, игрока и пользователя;
- `shared` — общий API-клиент, конфигурация и переиспользуемый UI.

Каталоги создаются по мере появления реального кода, чтобы структура не состояла из пустых папок.

## Реализованные маршруты

- `/` — главная страница;
- `/register` — заявка на подключение академии;
- `/verify-email` — подтверждение email кодом из письма;
- `/login` — получение JWT и вход;
- `/application` — защищённая страница статуса заявки и повторной отправки кода;
- `/dashboard` — защищённая основа будущей ролевой панели.
- `/platform/applications` — панель `SUPER_ADMIN` для фильтрации, одобрения и отклонения заявок.
- `/academy` — обзор одобренной академии и основные показатели;
- `/academy/groups` — создание, изменение и удаление групп;
- `/academy/players` — игроки, фильтр по группам и родительские контакты.

JWT хранится в `sessionStorage` до конца браузерной сессии или до истечения срока токена. Backend сейчас выдаёт токен на 15 минут и не поддерживает refresh-токены.

После входа frontend также запрашивает `/api/auth/academies`. Ответ содержит доступные
академии и роли пользователя, поэтому кабинет не зависит от сохранённого в браузере `academyId`.
