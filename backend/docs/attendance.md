# Посещаемость

Администратор работает со всеми группами своей академии. Тренер видит и изменяет
посещаемость только назначенных ему групп. Родитель не получает доступ к общей
ведомости.

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/academies/{academyId}/groups/{groupId}/attendance/{date}` | Ведомость группы за дату |
| PUT | `/api/academies/{academyId}/groups/{groupId}/attendance/{date}` | Создать или обновить отметки |

Дата передаётся в формате `YYYY-MM-DD` и не может быть будущей. Если ведомость
ещё не сохранена, GET возвращает `saved=false`, `version=0` и текущий состав
группы с пустыми статусами.

PUT принимает текущую версию и отметку для каждого игрока группы:

```json
{
  "version": 0,
  "records": [
    {
      "playerId": "UUID игрока",
      "status": "PRESENT",
      "comment": "Пришёл вовремя"
    }
  ]
}
```

Допустимые статусы: `PRESENT`, `ABSENT`, `LATE`, `EXCUSED`. Повтор игрока,
пропущенный игрок, игрок другой группы или академии возвращают 400. При
одновременном изменении ведомости устаревшая версия возвращает 409.

В базе одна ведомость уникальна для сочетания академии, группы и даты. Составные
внешние ключи дополнительно блокируют связь с группой, игроком или ведомостью
другой академии.
