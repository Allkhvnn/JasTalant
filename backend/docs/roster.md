# Группы и игроки

Все URL ниже начинаются с `/api/academies/{academyId}`. Нужен Bearer JWT.
ADMIN управляет своей академией; SUPER_ADMIN — любой. COACH читает только
назначенные группы и их игроков. PARENT не имеет доступа к этим общим спискам;
отдельный просмотр своего ребёнка будет реализован после подтверждения связи.

| Метод | Путь | Операция |
|---|---|---|
| GET / POST | `/groups` | Список / создание группы |
| GET / PUT / DELETE | `/groups/{id}` | Просмотр / изменение / удаление |
| GET | `/groups/{id}/coaches` | Назначенные тренеры |
| PUT / DELETE | `/groups/{id}/coaches/{userId}` | Назначить / снять тренера |
| GET | `/members?role=COACH` | Участники академии с указанной ролью |
| GET / POST | `/players` | Список / создание игрока |
| GET / PUT / DELETE | `/players/{id}` | Просмотр / изменение / удаление |

Изменения разрешены только ADMIN/SUPER_ADMIN. Создание возвращает 201, изменение
200, удаление/назначение — 204. Повторное назначение того же тренера не создаёт
дубликат. Тренер должен уже иметь членство с ролью COACH в этой академии. API
приглашения создаёт членство и роль; само назначение на группу новых ролей не создаёт.

Пример POST группы:

```json
{"name":"Младшая группа","ageCategory":"U10"}
```

Пример POST игрока:

```json
{
  "groupId":"UUID группы",
  "fullName":"Имя игрока",
  "dateOfBirth":"2015-06-10",
  "parentName":"Имя родителя",
  "parentPhone":"+77001234567",
  "parentEmail":"parent@example.kz"
}
```

Группа обязательна; контактные поля необязательны (можно опустить или передать null).
Дата рождения должна быть в прошлом. У игрока в MVP одна группа. Перемещение
между группами одной академии выполняется изменением groupId.

PUT принимает полный набор полей в `details` и текущую `version` из ответа GET:

```json
{"version":0,"details":{"name":"Новое название","ageCategory":"U11"}}
```

PUT игрока аналогичен: `details` содержит поля POST игрока. Устаревшая версия
возвращает 409. Пропущенные необязательные контакты при PUT очищаются.
Нельзя удалить группу с игроками: ответ 409. Сначала переместите или удалите игроков.
Удаление группы очищает назначения тренеров; снятие роли COACH очищает назначения
этого членства на уровне БД.

Списки поддерживают `page=0&size=20`, максимальный size — 100. Список игроков
поддерживает фильтр `groupId`. Ответ: `items`, `page`, `size`, `totalElements`.
Неназначенная тренеру группа или чужой ID возвращают 404. Пагинация и количество
элементов учитывают только доступные пользователю записи.

Миграция V4 обеспечивает соответствие академии игрока, группы и членства тренера
составными внешними ключами. academyId берётся из пути и проверяется по текущему
пользователю; передача произвольного UUID не даёт доступа.
