# Языки интерфейса и писем

Поддерживаются `ru`, `kk` и `en`. Frontend сохраняет выбор в
`localStorage` (`jastalant.locale`) и передаёт `Accept-Language` в JSON,
multipart и download-запросах. Например, `kk-KZ` выбирает казахский язык.

Backend выбирает язык письма по заголовку запроса. Без заголовка или при
неподдерживаемом языке используется русский. Поддерживаются региональные
варианты и приоритеты в `Accept-Language`, например `de-DE,en;q=0.8`.

Пять почтовых шаблонов лежат в `src/main/resources/i18n/mail*.properties`:
подтверждение email (24 часа), восстановление пароля (1 час), приглашение
в академию (72 часа), одобрение и отказ по заявке академии. Сроки действия токенов не изменены.

Приглашение использует язык отправляющего его администратора. Письмо
восстановления и повторное письмо подтверждения используют язык текущего
запроса. Предпочтение языка аккаунта в базе пока не хранится. Для писем о решении
язык сохраняется отдельно в заявке при регистрации и повторной подаче; язык
супер админа не влияет на письмо заявителю. Эти письма отправляются из очереди,
подробнее в [onboarding.md](onboarding.md#письма-о-решении).

Ссылки приглашения и восстановления содержат `lang=ru|kk|en` отдельно от
`token`. При открытии ссылки frontend выбирает этот язык, даже если ранее
был сохранён другой. Письма о решении содержат `/application?lang=ru|kk|en` без
токена авторизации: для просмотра своей заявки нужен вход в аккаунт.
Код подтверждения email остаётся без изменений.

Описание сайта и `document.lang` обновляются при выборе языка. До запуска
JavaScript HTML содержит нейтральное описание; название JasTalant остаётся
одинаковым для всех языков.

API сохраняет исходные детали ошибок. Frontend переводит 62 известные
ошибку, ошибки сети, пустые ответы 401/403 и общий HTTP fallback. Неизвестные
детали серверных ошибок заменяются сообщением с HTTP-статусом на выбранном
языке. Названия академий, имена и комментарии пользователей не переводятся.

## Проверка

Frontend: `npm test`, `npm run lint`, `npm run build` (Node.js 24).
Backend: `./gradlew test --no-daemon` (Java 21 и Docker для Testcontainers).
SMTP в тестах заменён mock-объектом, настоящие письма не отправляются.

Для ручной проверки выберите язык, вызовите ошибку входа, затем отправьте
тестовое подтверждение email, восстановление и приглашение. В локальном
профиле письма доступны в Mailpit на http://localhost:8025. Проверьте язык
темы и текста, а также открытие ссылок в браузере с другим сохранённым языком.
