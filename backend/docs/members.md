# Управление участниками академии

Администратор получает единый список участников и может менять роли `ADMIN`,
`COACH`, `PARENT`, а также включать и отключать доступ.

```text
GET /api/academies/{academyId}/members
GET /api/academies/{academyId}/members?role=COACH
PUT /api/academies/{academyId}/members/{userId}
```

Обновление принимает текущую версию членства:

```json
{
  "version": 0,
  "roles": ["COACH", "PARENT"],
  "active": true
}
```

У членства должна оставаться хотя бы одна роль. Последнего активного администратора
нельзя отключить или лишить роли `ADMIN`. Изменения этой проверки сериализуются
блокировкой строки академии, поэтому два параллельных запроса не смогут оставить
академию без администратора.

Отключение доступа не удаляет членство и историю. Пользователь сразу перестаёт
видеть академию в `/api/auth/academies`, а защищённые сервисы возвращают 403.
Повторное включение восстанавливает доступ. Удаление роли тренера очищает назначения
групп, а удаление роли родителя — связи с детьми через внешние ключи базы данных.
