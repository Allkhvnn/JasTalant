# Показатели развития игроков

Одна оценка хранит срез развития игрока на дату по шкале от `0.0` до `10.0`:

- `technique` — техника;
- `speed` — скорость;
- `endurance` — выносливость;
- `physicalFitness` — физическая подготовка;
- `gameIntelligence` — игровой интеллект.

Для игрока разрешена одна оценка на дату. Будущие даты запрещены. У записи есть
необязательный комментарий, автор, время создания и версия для защиты от
перезаписи устаревшими данными.

## API сотрудников

Базовый путь:

```text
/api/academies/{academyId}/players/{playerId}/development-assessments
```

- `GET ?page=0&size=20` — история от новых оценок к старым;
- `POST` — создать оценку;
- `PUT /{assessmentId}` — обновить оценку с текущей `version`;
- `DELETE /{assessmentId}` — удалить оценку.

`ADMIN` работает со всеми игроками своей академии. `COACH` работает только с
игроками назначенных ему групп. Чужие игроки и академии возвращаются как не найденные.

## API родителя

```text
GET /api/academies/{academyId}/parent/players/{playerId}/development-assessments?page=0&size=20
```

Родитель может читать историю только после подтверждённой связи в `parent_players`.
Создавать, изменять и удалять оценки родитель не может.
