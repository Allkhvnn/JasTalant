# Миграции

SQL-миграции добавляются здесь вместе с моделью данных: `V1__create_academies.sql`,
`V2__...sql`. Уже применённые миграции не редактируются.

Схемой управляет Flyway; Hibernate только проверяет соответствие сущностям.
`V1__create_academies_users_and_memberships.sql` создаёт академии, пользователей
и членство с ролями ADMIN/COACH. Email хранится в нижнем регистре и уникален
глобально; пара academy_id/user_id уникальна. Удаление связанных записей
ограничено внешними ключами, каскадного удаления нет.

`V2__separate_platform_and_academy_roles.sql` добавляет `platform_role` у пользователей
(USER по умолчанию, SUPER_ADMIN для владельца), переносит роли членства в таблицу
`academy_membership_roles` и добавляет PARENT. Одно членство поддерживает несколько
ролей; SUPER_ADMIN в таблице ролей академии запрещён. При удалении членства его
строки ролей удаляются каскадно. V1 не изменяется.

V3 добавляет подтверждение email и заявки на подключение. Существующие пользователи
получают email_verified=false: подтверждение выполняется через вход и повторную
отправку кода. Существующий SUPER_ADMIN также должен подтвердить email.
Код хранится только как SHA-256, имеет срок действия и уничтожается при использовании.
V1 и V2 сохранены без изменений.

V4 создаёт training_groups, players и group_coaches. Составные внешние ключи
проверяют совпадение academy_id; назначение тренера ссылается также на роль COACH
в academy_membership_roles. Удаление роли/членства очищает назначения. Удаление
группы с игроками запрещено. JPA-сущности групп и игроков используют version.

V5 добавляет одноразовые приглашения COACH/PARENT, выбранных для приглашения
игроков и подтверждённые связи parent_players. Токен хранится как SHA-256,
активное приглашение уникально для пары академия/email. Составные внешние ключи
запрещают приглашать ребёнка и связывать родителя из другой академии. Удаление
роли PARENT, членства или игрока каскадно удаляет связь родитель/игрок.

V6 добавляет журнал посещаемости: одна ведомость на группу и дату, четыре статуса
игрока и необязательный комментарий. Составные внешние ключи не позволяют связать
ведомость или отметку с другой академией. Удаление группы удаляет её ведомости;
игрока с сохранённой историей посещаемости удалить нельзя.

V7 добавляет историю показателей развития игрока. Одна запись содержит пять оценок
по шкале 0–10, дату, комментарий и автора; пара игрок/дата уникальна. Составной
внешний ключ не позволяет связать оценку с игроком другой академии. При удалении
игрока его оценки удаляются каскадно.

V8 добавляет календарь тренировок с группой, тренером, временем, местом и статусом.
Ведомость посещаемости получает необязательную ссылку на занятие. Старые ведомости
остаются доступными по группе и дате, а новые занятия поддерживают несколько
независимых тренировок одной группы за день. Составной внешний ключ проверяет
совпадение академии, группы и даты занятия с ведомостью.

V9 добавляет членству флаг активного доступа и версию для оптимистической блокировки.
Отключение членства сохраняет роли и исторические связи, но запрещает дальнейшую
работу пользователя в академии.
